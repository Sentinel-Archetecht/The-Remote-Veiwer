Fee Edge Cases – Locked Decisions
Full charge stays
Once a Ghost Tax or verification fee is charged for the month, the full amount remains even if the Viewer verifies later that same month. No proration.
Un-verification restarts Ghost Tax
If a previously verified Viewer chooses to un-verify, Ghost Tax restarts immediately.
The system must show a clear notification at the moment the Viewer confirms the change.
Status is per blockchain address
Verification and fee status are tied to the blockchain address.
All devices and sessions under the same address share the same status.
24-hour window keeps running
The verification window does not reset on failed or abandoned attempts.
Every attempt is logged.
Scrolling still incurs minimum fee
If a Viewer never posts, comments, or shares but only scrolls / consumes content, a minimum $15 Ghost Tax still applies for service use.
Timing source
All windows and deadlines are measured by on-device timing plus telemetry.
