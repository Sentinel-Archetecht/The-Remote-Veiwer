Privacy-Preserving Verification
Hard Requirement
Legal government ID is required to verify age. This is non-negotiable.
What is stored
Only the age-verification result (whether the Viewer meets the required age threshold).
The result is tied solely to the Viewer’s blockchain address.
The government ID itself is never stored.
What is still protected
No email, phone number, device fingerprint, or IP is required or retained.
No other personal data from the ID is kept.
Hydra remains invisible.
All fee, tier, Ghost Tax, and orb logic continues to read only address-level status.
Method
Viewer proves control of their blockchain address (signature or zero-knowledge proof).
Viewer completes government ID age check.
On success, the address is marked age-verified and the chosen Red/Blue orb is recorded.
Plain-language confirmation is shown to the Viewer.
Un-verification
A Viewer may un-verify. Doing so immediately restarts Ghost Tax and a clear plain-language notice is shown at confirmation.
